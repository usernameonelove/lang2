# Языки — личный словарь

Мобильное веб-приложение для изучения языков. Работает как статический сайт, поэтому подходит для GitHub Pages.

## Возможности

- создание любого количества языков;
- внутри каждого языка две папки: **Словарь** и **Фразы и предложения**;
- карточки «оригинал → перевод»;
- добавление, редактирование и удаление карточек;
- поиск по карточкам;
- режим обучения с переворотом карточки и перемешиванием;
- экспорт всего набора или отдельного языка в JSON;
- импорт JSON;
- локальное хранение данных в браузере;
- PWA: после добавления сайта на экран «Домой» iPhone приложение открывается отдельным окном и может работать офлайн после первого открытия.

## Публикация на GitHub Pages

1. Создай новый GitHub repository.
2. Загрузи в корень репозитория: `index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`.
6. Сохрани настройки и открой выданную GitHub ссылку.

## iPhone

Открой ссылку в Safari → **Поделиться** → **На экран «Домой»**. После этого приложение будет запускаться как отдельное окно.

## Данные

Карточки сохраняются в `localStorage` конкретного браузера. Перед очисткой Safari/Chrome или переносом на другой телефон используй **Экспортировать всё**.
